# Danang Descent

InterContinental Danang Sun Peninsula Resort

This product is part of Art Digital Journey.

The guest accesses it by scanning one unique aesthetic QR code integrated into a physical artwork inside the resort.

The experience must feel like entering the resort digitally.

Do NOT design a dashboard.

Do NOT design a SaaS interface.

Do NOT create a generic luxury Linktree.

Do NOT use grids of rounded cards everywhere.

Do NOT use desktop-first patterns.

This experience is primarily designed for a smartphone held vertically.



CORE NAVIGATION CONCEPT

The entire main experience must follow the real physical geography of the resort.

The resort is organized into four vertical levels:

HEAVEN
↓
SKY
↓
EARTH
↓
SEA

The user scrolls vertically through these four worlds.

The vertical scroll represents the physical descent through the resort.

Inside each world, the user swipes horizontally to discover the places located in that level.

Therefore:

VERTICAL SCROLL = MOVE THROUGH THE RESORT

HORIZONTAL SWIPE = EXPLORE PLACES WITHIN THAT LEVEL

TAP = TAKE ACTION

This navigation philosophy must be visible and understandable without explanation.



NAM TRAM NAVIGATION

Use the iconic Nam Tram as the visual navigation thread connecting the four worlds.

Create a very thin vertical navigation rail fixed discreetly along the right edge of the mobile interface.

Show:

HEAVEN
│
SKY
│
EARTH
│
SEA

Include a small stylized marker inspired by a Nam Tram cabin.

Do NOT make it realistic or cartoonish.

It should feel like luxury architectural signage.

As the user scrolls:

the marker moves vertically

the current level becomes active

the completed part of the rail subtly changes appearance

the next level remains understated

The user can tap:

HEAVEN
SKY
EARTH
SEA

to jump directly to that section.

Keep the rail extremely discreet.

It must enhance the experience, not dominate it.



IMPORTANT GEOGRAPHIC RULE

Place resort venues inside Heaven / Sky / Earth / Sea according to their actual physical position in the resort, not according to arbitrary marketing categories.

Do not put Instagram in Sky just because it feels social.

Do not put spa in Earth simply because wellness feels natural.

Only physical locations belong inside the geographic journey.

Digital services that are not tied to a physical level must remain outside this geography.

VISUAL TRANSITIONS

The vertical transition between worlds is essential.

Do not simply place four sections one after another.

Make them feel like environments.

HEAVEN → SKY

Architecture fades into open horizon.

SKY → EARTH

Horizon gradually becomes vegetation.

EARTH → SEA

Jungle opens into coastline and water.

Use subtle techniques:

background color interpolation

image masking

slow parallax

soft typography movement

gradient transitions

image reveals

Avoid flashy motion.

Avoid excessive animations.

Respect reduced-motion preferences.



HORIZONTAL UX RULES

This is a responsive mobile experience.

Horizontal destination sections must:

support touch swipe

use CSS scroll snapping

feel natural on iPhone and Android

keep the next item partially visible

never trap vertical scrolling

allow one-handed interaction

have smooth momentum

Recommended width:

Each main destination panel should use approximately 82–88% of the mobile viewport width.

Spacing between panels:

approximately 12–16px.

Do not use tiny cards.

Do not make users swipe through 10 items to reach something important.

If a level contains many destinations, use:

FEATURED DESTINATIONS

then:

VIEW ALL

for the secondary ones.



IMPORTANT MOBILE GESTURE RULE

Vertical scroll must always remain dominant.

Horizontal swipe should only activate naturally when the user intentionally swipes horizontally inside a destination rail.

Do not create custom gesture behavior that makes the user fight the page.

Use native overflow scrolling whenever possible.
